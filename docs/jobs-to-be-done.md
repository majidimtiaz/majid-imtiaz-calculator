# Jobs To Be Done

Each job describes what a person needs to get done, whether or not this app exists. Role IDs refer to `docs/app-roles.md`.

## J-1 (R-1 Pointer user)

When I'm splitting a restaurant bill with friends, I want to work out each person's share quickly, so I can tell everyone what they owe before we leave the table.

## J-2 (R-1 Pointer user)

When I'm checking a shop receipt after paying, I want to add up the items myself, so I can be sure I wasn't overcharged.

## J-3 (R-1 Pointer user)

When I get a figure wrong partway through working out a sum, I want to correct that mistake without starting the whole sum again, so I can reach the answer without wasting time.

## J-4 (R-2 Keyboard user)

When I'm working through figures while typing at my desk, I want to run quick sums without breaking my flow, so I can finish the task faster.

## J-5 (R-2 Keyboard user)

When I'm checking the totals in an invoice or report before sending it, I want to be certain every result is exactly right, and to be told plainly when a calculation has no valid answer, so I can send it without errors.
